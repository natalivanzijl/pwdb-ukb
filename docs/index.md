# pwdb-ukb

**pwdb-ukb** is a database of *in silico* pulse waves based on the UK Biobank. 

*News: This documentation is currently being prepared for the release of the Pulse Wave DataBase based on the UK Biobank (pwdb-ukb). We hope to release the database shortly.*

## Description

This database has been designed to be representative of a population of men and women aged 47-77 without overt cardiovascular disease or diabetes, based on *in vivo* data from the UK Biobank. Idealised pulse waves (pressure, velocity, luminal area, PPG) of 10,000+ virtual subjects were simulated at common measurement sites (e.g., brachial artery, finger) and central sites (e.g., aortic root) that would require invasive measurements. 

## Purpose

This database is a helpful resource for anyone interested in pulse wave analysis.  In the first instance, it has been generated as part of the [VITAL project](https://vital-horizoneurope.eu/), where it will be used to benchmark human digital twins before clinical validation.

## Downloading the database

The database will be made publicly available at DOI: 10.5281/zenodo.21902819 in CSV format.

## Reproducing the database

The database was generated based on the methodology from [Peter Charlton's pwdb](https://github.com/peterhcharlton/pwdb/wiki/Reproducing-the-Pulse-Wave-Database). The scripts and detailed instructions to reproduce the database will be made available [here](./code/).
